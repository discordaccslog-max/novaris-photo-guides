# Novaris Photo Guides

Storefront and Field Kit for Novaris Photo Guides: six interactive photography field guides that run in the browser and unlock with a license code, plus 25 printable PDF guides with paid add-ons. Plain HTML, CSS, and JavaScript, deployed as a static site on Vercel at https://novaris-photo-guides.vercel.app.

## How it works

- **Storefront**: product pages, policies, and FAQ at the site root.
- **Field Kit** (`/field-kit/`): the web app that holds all five guides. It works on phones, tablets, and computers, installs to the home screen, and works offline once loaded (service worker in `field-kit/sw.js`). Saved work and licenses live only in the buyer's browser.
- **Confirmation pages** (`/thank-you/<slug>/`): not linked anywhere and marked `noindex`. Each one issues a license code, activates it in that browser, and offers a PDF confirmation. When the payment provider adds an order ID to the URL (`session_id`, `order_id`, `order`, `transaction_id`, `txn_id`, or `token`), the code is generated from it, so the same order always produces the same code.
- **PDF guides**: 25 products in `js/products.js` with `format: "pdf"`, each with 3–4 add-ons (`options`). Their pages are generated by `tools/pdf-pages.js` from the guide content in `catalog/content/`, and the home page lists them in a filterable library. The PDFs themselves are built with `node tools/make-catalog-pdfs.js` into `pdf-guides/catalog/`, which is kept out of git and off the public site.
- **License codes** (`js/license.js`): `NOVA-XX-XXXX-XXXX-XXXX`, using a 31-character alphabet with no 0/O or 1/I/L, and two checksums that reject every single-character error and adjacent swap. A Complete Reference Library code (`CR`) unlocks all five guides.

## Adding checkout links

Edit `js/products.js` and paste each product's checkout link into `checkoutUrl`. Buy buttons appear only for products with a link, under a required "I agree to the Terms of Service and Refund Policy" checkbox.

In your payment provider, set each product's success (redirect) URL to its confirmation page with the provider's order or session ID placeholder, for example:

```
https://novaris-photo-guides.vercel.app/thank-you/portrait-session-guide/?session_id={CHECKOUT_SESSION_ID}
```

Then run `npm run kit` to rebuild the fulfillment kit with checkout screenshots.

### PDF guides and add-ons

PDF guides don't use confirmation pages or license codes. Use a payment provider with digital delivery (a download link shown after payment and emailed to the buyer), and upload each guide's PDF from `pdf-guides/catalog/` plus one file per add-on.

When a buyer ticks add-ons, the buy button adds them to the checkout link as `?addons=id1,id2` (ids are the `options[].id` values in `js/products.js`), and the button and price box show the new total. **Your provider must read that parameter or charge the add-ons another way**: for example, set each add-on up as an optional upsell or a separate product in the provider. Check that a test order with add-ons is charged and delivered correctly before going live.

## Support: replacement licenses

```
npm run license -- portrait-session-guide <order-id>   # the code issued for that order
npm run license -- portrait-session-guide              # a new code (orders without an ID)
npm run license -- check NOVA-PT-XXXX-XXXX-XXXX         # validate a code
```

## Commands

| Command | What it does |
| --- | --- |
| `npm run build` | Regenerates the storefront pages, confirmation pages, sitemap, and service worker from `tools/` |
| `npm test` | Unit tests (`node --test`) and browser tests (Playwright: desktop Chromium, mobile Chromium, mobile WebKit) |
| `npm run serve` | Local server at http://localhost:8642 |
| `npm run kit` | Rebuilds `fulfillment-kit/` from the live site (screenshots, video, PDFs) |

Product names and prices come from `js/products.js`; the support email from `js/site-config.js`. Guide content is in `field-kit/guides/`. Run `npm run build` after changing any of them, then deploy with `vercel deploy --prod`.

## Structure

- `index.html`, `*-guide.html` (Field Kit and PDF guide pages), `complete-reference-library.html`, policies, `faq.html`, `contact.html`, `about.html`, `consumer-rights.html`, `404.html`: generated by `tools/build.js`
- `thank-you/<slug>/index.html`: confirmation pages (generated); logic in `js/thank-you.js`
- `field-kit/`: the app (`app.js`, `views/`, `guides/`, `diagrams.js`, `export.js`, `store.js`)
- `js/`: shared modules (`license.js`, `license-store.js`, `pdf.js`, `confirmation.js`, `exposure.js`, `sun.js`) and storefront scripts
- `fonts/`: self-hosted Fraunces and Inter (SIL Open Font License)
- `tests/`: unit and browser tests; `tools/`: build, server, kit, and support tools
